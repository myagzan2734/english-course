# Pre-Intermediate Çalışma Defteri

Speakout 2nd Edition Pre-Intermediate ünitelerine göre hazırlanmış kişisel çalışma uygulaması.
Alıştırmalar, örnek cümleler, dinleme metinleri ve sınavlar özgün olarak yazılmıştır; kitabın metinlerini veya ses kayıtlarını içermez.
Bu proje Pearson ile bağlantılı değildir.

Güncelleme yaparken `sw.js` içindeki `CACHE` sürüm adını değiştirmeyi unutma.
